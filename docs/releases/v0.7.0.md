# MCP Event Intelligence v0.7.0

v0.7.0 turns the embedded integration surface into a runtime-neutral host kit.

The new `mcp-event-intelligence/embedded` export lets an existing runtime keep ownership of MCP connections, authorization, storage policy and its own continuation model while EI owns durable future conditions, correlation and wake activation.

Highlights:

- `createEmbeddedEventIntelligence()` high-level installer;
- `createActivationDispatcher()` with host-owned target resolution and receipt semantics;
- portable `createEventIntelligenceAgentTools()` descriptors;
- opaque runtime-defined continuation target kinds;
- runtime-neutral activation/evidence type aliases;
- git-install packaging support through `prepare`;
- generic tests proving the host kit does not depend on Muffin or Artemis concepts.

This remains an **embedded** architecture. Event Intelligence is not introduced as a separate MCP server between an agent runtime and its event sources.
