# MCP Event Intelligence v0.1.1

Provider integration patch for runtimes that want to expose experimental MCP Events without copying Event Intelligence protocol glue.

## New package surface

```js
import {
  createMcpEventsProvider,
} from 'mcp-event-intelligence/provider';
```

The adapter owns experimental Events capability advertisement, `server/discover`, `events/list`, `events/poll`, common occurrence validation and response shapes. Provider runtimes keep ownership of authentication, domain event definitions, data access and opaque cursor semantics.

The existing store-backed `ExperimentalMcpEventsServer` and cursor helpers are also exported through the provider subpath for lower-level use.

## Compatibility

This is a package/API patch. Persisted Event Intelligence protocol and composite-trigger schema versions remain unchanged from v0.1.0.

MCP Events remains experimental and this adapter does not claim finalized MCP Events conformance.
