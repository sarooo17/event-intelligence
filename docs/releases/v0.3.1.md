# MCP Event Intelligence v0.3.1

Small reliability and public-polish release before wider distribution.

## Reliability

The lease-claim contention test now always waits for the blocked delivery worker and drains the store before removing its temporary directory. This removes an intermittent cleanup race that could surface as `ENOTEMPTY` and mask the real assertion state.

The suite also adds repeated direct claim contention and full coordinator contention stress coverage.

## Documentation

Public docs are aligned with the current package:

- package line: **0.3.x**;
- internal persisted protocol/schema compatibility line: **v0.1**;
- scoped multi-tenant host boundaries;
- deterministic `trigger_plan` / `planTrigger()`;
- first-class continuation contracts;
- Activation Envelope hydration and untrusted evidence semantics;
- live npm + MCP Registry release status.

The obsolete one-shot v0.1.0 release workflow has been removed.

## Compatibility

No runtime protocol break. Existing 0.3.0 integrations remain compatible.
