# MCP Event Intelligence v0.1.0

**Durable temporal event intelligence for sleeping agents.**

v0.1.0 is the first public reference release.

## Embedded host integration

The primary package surface is `mcp-event-intelligence/host`. An existing harness passes its MCP registry once; Event Intelligence discovers and reuses Events-capable clients without taking ownership of provider credentials. Tools-only MCPs are ignored automatically.

A single in-process wake dispatcher can route matching continuations to multiple agents using the trigger target.

## Standard MCP control plane

The npm package also exposes the Event Intelligence control plane through a standard MCP stdio server:

```bash
npx mcp-event-intelligence mcp
```

The adapter uses the official TypeScript SDK v2 and targets MCP 2026-07-28. Read tools are available by default; persistent mutations are an explicit operator opt-in and still pass through the existing confirmation-gated TriggerControlPlane.

The release includes validated MCP Registry metadata for:

```text
io.github.sarooo17/event-intelligence
```

Actual Registry publication follows the public npm artifact.

## What it proves

An agent can delegate a future condition to a durable event layer, stop running, and later be resumed by its host only when the world satisfies that condition. Standalone deployments can use the signed wake callback path.

The condition can span:

- multiple event sources;
- temporal windows and absence;
- deterministic correlation;
- derived higher-level events;
- versioned derived-event contracts.

## Reliability evidence

The v0.1 acceptance checkpoint includes:

- full black-box service execution;
- automatic discovery from a host-owned MCP registry without duplicate provider credentials;
- tools-only MCPs ignored and Events-capable MCPs attached automatically;
- multi-agent in-process wake routing plus signed standalone callback coverage;
- persistent runtime receipt;
- replay without a second wake;
- contract evolution and ambiguity rejection;
- process shutdown while an absence deadline is pending;
- restart on the same datastore after the deadline;
- recovery and wake without a new provider event;
- verified hash-linked audit chain;
- live GitHub webhook ingress regression.

## Scope

This is a reference implementation and experimental protocol/runtime layer.

It is not an official MCP specification, and its MCP Events support tracks experimental work that may change.

The JSONL store is intentionally single-writer and should not be treated as production HA storage.

## Install

From source:

```bash
npm ci
npm run check
SERVICE_AUTH_TOKEN="$(openssl rand -hex 32)" npm start
```

After the npm artifact is published:

```bash
SERVICE_AUTH_TOKEN="$(openssl rand -hex 32)" npx mcp-event-intelligence
```

Docker:

```bash
docker build -t mcp-event-intelligence:0.1.0 .
```
