# MCP Event Intelligence v0.4.0

v0.4.0 aligns Event Intelligence's MCP event-ingress boundary with the current Triggers & Events working draft while keeping EI's durable correlation and wake semantics independent from transport.

## MCP Events alignment

- direct extension negotiation through `capabilities.extensions["io.modelcontextprotocol/events"]`;
- paginated `events/list`;
- current draft error semantics for invalid parameters, unknown events and unsupported methods;
- nullable replay cursors and `_meta` preservation;
- subscription arguments validated against advertised `inputSchema`;
- server-directed poll scheduling through `nextPollMs`;
- `hasMore` and `truncated` tracked as separate semantics.

## Durable subscriptions

Event source discovery and durable subscriptions are now distinct.

A source is the descriptor advertised by an MCP server. A subscription is the host connection + event name + canonical MCP arguments, with its own cursor and delivery state. This allows multiple durable intents to consume the same event type with different server-side arguments without sharing progress.

Existing trigger definitions remain compatible: clauses without arguments read as `arguments: {}`.

## Delivery modes

The host integration can consume:

- poll through the existing MCP request surface;
- push through a host-owned `openEventStream` adapter;
- webhook through a host-owned `createWebhookSubscription` adapter.

All modes normalize into the same EventOccurrence pipeline before predicates, temporal logic, derived events or runtime wake. The host continues to own transports, credentials, public callback infrastructure and authorization.

## Verification

Regression coverage includes:

- extension negotiation and paginated discovery;
- input/payload validation and draft errors;
- nullable cursors and metadata;
- per-argument subscription/cursor isolation;
- server-directed poll scheduling and bounded draining;
- push and webhook ingestion through the same trigger engine;
- a conformance-shaped discovery/poll regression derived from the current draft.

Compatibility snapshot: experimental-ext-triggers-events PR #7 and modelcontextprotocol/conformance PR #521 as observed on 2026-09-25. MCP Events remains experimental.
