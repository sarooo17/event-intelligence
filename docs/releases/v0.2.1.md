# MCP Event Intelligence v0.2.1

Patch release focused on deterministic shutdown and stronger evidence for scoped isolation.

## Fixed

- `host.close()` now waits for in-flight MCP polls, retry/deadline scheduler work and queued persistent writes;
- store cleanup no longer races background JSONL appends after shutdown;
- regression coverage verifies that audit, event-source discovery, cursors, occurrences and wake records stay inside their tenant scope.

## Clarified ERP provider boundary

`mcp-event-intelligence/provider/erpnext` is a typed provider factory. It defines event descriptors, schemas and validation, while the host owns real ERP authentication and queries. The production ERPNext proof lives in `world-capability-mcp`, which uses the generic provider contract against authenticated ERPNext/Frappe data access.
