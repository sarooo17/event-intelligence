# MCP Event Intelligence v0.8.2

v0.8.2 reduces repetitive embedded-runtime glue while keeping Event Intelligence runtime-neutral.

## Reusable embedded primitives

- deterministic namespaced wake receipts through `activation.receiptNamespace` and `createDeterministicReceiptId()`;
- direct static iterable support for host-owned event connections;
- `integration.diagnostics()` for normalized event-source readiness;
- `integration.bind()` for generic tool adaptation, registration and lifecycle wiring;
- host-owned `projectError` alongside the existing success projection path.

## Review fixes

The release also closes three review findings before publication:

- one-shot generators are materialized once instead of being exhausted on refresh;
- receipt hash components use unambiguous tuple encoding;
- diagnostics merge registry refresh outcomes so failed attachment attempts remain visible.

These APIs remain callback-driven. Event Intelligence does not gain knowledge of Muffin, Artemis, ChatGPT, Claude, Turn, Execution, thread or vendor-specific tool formats.
