# MCP Event Intelligence v0.7.1

Patch release for the runtime-neutral embedded host kit introduced in v0.7.0.

- serializes and coalesces concurrent MCP registry refreshes;
- prevents a host from observing a connection as attached before its event descriptors have finished discovery;
- adds a regression test reproducing the race between a registry subscription callback and an explicit refresh.

The embedded architecture and public host contracts are otherwise unchanged from v0.7.0.
