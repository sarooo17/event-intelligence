# MCP Event Intelligence v0.8.1

v0.8.1 is a corrective patch for the runtime-neutral embedded integration introduced in v0.8.0.

## Fixed

- a host `projectResult()` failure after `trigger_create` has already committed no longer turns the durable success into an apparent create failure; Event Intelligence falls back to the canonical inline receipt/state so callers are not encouraged to retry a mutation that already happened;
- the deprecated `authorize()` integration path again normalizes ordinary callback failures into a portable tool result, preserving pre-v0.8 behavior;
- the new `control()` path continues to pass native host interrupt/suspension exceptions through unchanged.

## Regression coverage

The release adds explicit tests for both failure modes and retains the full runtime-neutral integration suite.

## Release integrity

v0.8.0 was published before these post-review fixes landed on `main`. npm versions are immutable, so v0.8.1 is the first published artifact containing the complete reviewed v0.8 integration plus these fixes.
