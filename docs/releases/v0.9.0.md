# v0.9.0 — Observability and host conformance

Event Intelligence v0.9.0 makes embedded integrations easier to operate and verify without adding runtime- or vendor-specific adapters.

## Runtime-neutral observability

The new `mcp-event-intelligence/observability` entry point emits structured, versioned `ei.*` operational events through a host-supplied sink.

Coverage includes runtime lifecycle, MCP/event-source health, trigger mutations, matches, wake delivery, retries, dead-letter transitions and scheduler failures.

Observability is intentionally:

- **host-owned** — adapt it to an existing logger, OpenTelemetry, Sentry, Datadog or another backend;
- **best-effort** — sink failures never change EI semantics;
- **non-blocking** — slow async telemetry cannot stall event processing;
- **privacy-bounded** — event payloads, evidence, continuation instructions and credential-like metadata are excluded/redacted.

The durable hash-linked audit chain is unchanged and remains a separate source of tamper-evident historical evidence.

## Host conformance

The new `mcp-event-intelligence/conformance` entry point lets any embedding runtime validate its EI integration through a six-method host harness.

The v1 suite verifies:

1. threshold and one-shot delivery;
2. replay deduplication on a persistent trigger;
3. trigger durability across host restart;
4. bounded `maxFirings`;
5. required structured observability and payload non-leakage.

Reports use the machine-readable schema `event-intelligence.host-conformance.v1`.

A reference embedded host is included and can be exercised with:

```bash
npm run conformance:host
```

## Architecture boundary

This release keeps the v0.8 architecture intact: EI owns persistent future conditions, correlation, event-time state and wake reliability; embedding runtimes retain MCP credentials/transports, policy and approval semantics, continuation meaning, tool registration and their observability backend.

No Muffin-, Artemis-, OpenAI-, Anthropic- or logging-vendor-specific dispatch was added to EI core.
