# MCP Event Intelligence v0.11.0

Event Intelligence v0.11.0 adds a production shared-state path for horizontally scaled agent runtimes.

## Highlights

- transactional PostgreSQL persistence through `mcp-event-intelligence/storage/postgres`;
- database-authoritative EI scope isolation;
- distributed-atomic wake claims and trigger/version/partition leases;
- wake lease expiry takeover and stale-worker rejection;
- shared retry and dead-letter state across workers;
- concurrent audit writers preserve one valid hash-linked sequence;
- PostgreSQL 16 CI coverage with independent pools representing separate workers.

The default JSONL `PersistentEventStore` remains available for zero-dependency, single-process deployments and intentionally does not advertise distributed HA guarantees.
